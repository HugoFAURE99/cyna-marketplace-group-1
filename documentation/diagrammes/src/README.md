# Sources Mermaid CYNA

Ces fichiers constituent la source de vérité des schémas intégrés aux documents Word.
Ils sont rendus en SVG et en PNG haute résolution avant la génération des DOCX.

Le MCD est volontairement séparé en une vue métier et plusieurs vues de domaine :
un diagramme physique unique de 28 tables serait exhaustif, mais inutilisable dans un document A4.
